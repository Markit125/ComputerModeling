| Параметр                             | Описание                                       | Влияние на обучение                                                      |
| ------------------------------------ | ---------------------------------------------- | ------------------------------------------------------------------------ |
| **Размер карты (решетки)**           | Количество нейронов                            | Больше нейронов → выше детализация карты, но больше вычислений           |
| **Начальная скорость обучения (η₀)** | Обычно 0.1–0.5                                 | Слишком большая → нестабильность; слишком маленькая → медленное обучение |
| **Функция затухания η(t)**           | Уменьшает скорость обучения с течением времени | Способствует сходимости                                                  |
| **Радиус соседства (σ₀)**            | Определяет зону обновления                     | Большой в начале — глобальное обучение, малый позже — локальное          |
| **Функция расстояния**               | Евклидово или другое расстояние                | Определяет меру близости входа и нейрона                                 |
| **Количество эпох**                  | Длительность обучения                          | Недостаточно эпох — недообучение, слишком много — переобучение           |

### Способы инициализации весов

#### Случайная инициализация
Веса каждого нейрона задаются случайно в пределах диапазона входных данных.

Плюсы: просто реализуется.
Минусы: может потребоваться больше эпох для сходимости.

#### Инициализация выбором случайных входных векторов

Веса нейронов выбираются случайным образом из обучающего набора.

Плюсы: веса уже находятся в области данных.
Минусы: возможна плохая начальная топология.

#### Преобработка PCA (метод главных компонент)

Начальная карта распределяется по первым главным компонентам.

Плюсы: ускоряет обучение.
Минусы: сложнее реализовать.

### Выбор библиотек

#### MiniSom

Простая реализация.
Можно легко изменить параметры: размер карты, скорость обучения, радиус соседства.
Позволяет визуализировать U-матрицу, веса и кластеры.
Идеально подходит для учебных и исследовательских целей, не перегружена лишним, легко читается.
